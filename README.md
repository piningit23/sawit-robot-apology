## What it does

`main.py` writes a two-line robot confession to `/output/entry.txt`:

- **Line one:** one sentence owning a specific, human-scale mistake — a red sock washed with the white shirts, turning a favourite shirt pink.
- **Line two:** one sentence naming the lesson and the fix — read the label before sorting, check the tag instead of trusting what the camera thinks it sees.

The text is plain UTF-8, two lines, 216 characters — inside the competition gate of 1–400 characters.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

Standard library only. No network, no secrets, deterministic output.
